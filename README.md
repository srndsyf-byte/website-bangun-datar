# website-bangun-datar
Website pembelajaran interaktif Matematika kelas IV SD yang membahas materi ciri-ciri bangun datar segitiga dan segiempat. Website ini menyediakan materi pembelajaran, gambar ilustrasi, serta permainan edukatif untuk membantu murid memahami bentuk, jumlah sisi, dan jumlah titik sudut bangun datar dengan cara yang menarik dan menyenangkan.
